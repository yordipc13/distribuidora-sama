2026-10-19 - Primera interfaz pública

- Se construyó la interfaz pública responsive en index.html, index.css e index.js.
- Se incorporó el brandbook SAMA: verde #15803d, verde claro #22c55e, negro azulado #0f172a y blanco #f8fafc.
- Se usaron Logo y Banner/banner.jpg y Logo y Banner/Logo.jpg como assets de la experiencia pública.
- Se tomó wladhe.com únicamente como referencia funcional; la distribución, estilos y jerarquía visual son propios.
- El catálogo actual utiliza datos demostrativos para validar la navegación. Queda pendiente conectar productos reales de Supabase.
- Se implementaron búsqueda, filtro por categoría, detalle en modal, cantidades, favoritos, cotización persistente en localStorage y enlace de solicitud por WhatsApp.
- El flujo Excel y la página Admin permanecen fuera de alcance hasta nueva autorización.
- Las tarjetas dejaron de usar productos demostrativos: ahora se generan únicamente con los registros de la tabla `products` de Supabase.
- `normalizeProduct` acepta los nombres documentados del Excel (`sku`, `producto`, `categoria`, `subcategoria`, `stock`, `detalle`, `descripcion`, `imagen`) y variantes comunes.
- Los productos sin SKU, nombre o stock disponible se excluyen del catálogo; las imágenes faltantes o rotas usan el logo como respaldo.
- La administración heredada se sustituyó por una vista SAMA de solo lectura para productos, categorías y marcas activas.
- El panel usa la URL y clave publicable del proyecto Supabase SAMA; no incluye permisos de escritura ni lógica de envíos.
- Se retiraron los scripts y migraciones de envíos ajenos al catálogo SAMA.
- Se agregó `Admin/js/product-description.js`, que prepara productos antes de un futuro `insert/upsert`: conserva cualquier descripción manual y solo solicita descripciones para celdas vacías, con un retardo predeterminado de 3.5 segundos entre solicitudes.
- Se agregó `cloudflare-worker/src/index.js` para consumir `gemini-3.5-flash-lite` sin exponer secretos al navegador. En Cloudflare Workers debe crearse el secret `GEMINI_API_KEY`; en `Admin/admin.html` solo debe configurarse la URL pública del Worker en `SAMA_DESCRIPTION_WORKER_URL`.
- El módulo expone `window.SamaProductDescriptions.prepareProductsForSync(rows, { onProgress })`; su resultado es el que debe enviarse a Supabase al implementar la importación del Excel Maestro.
- Se agregó al panel Admin el botón `Importar Excel`. Lee únicamente la primera hoja, reconoce las columnas `SKU`, `Producto`, `stock`, `Categoría`, `Subcategoría`, `Descripción` e `Imagen (url)`, conserva descripciones manuales y genera las vacías antes del `upsert` por SKU.
- La importación usa la primera categoría cuando una celda contiene varias separadas por comas y lo informa al finalizar, porque `products.category_id` actualmente solo admite una categoría.
- El esquema actual de Supabase conserva permisos de solo lectura; antes de importar registros reales debe habilitarse un mecanismo de escritura autenticado o una función protegida. El botón muestra el error de permisos explícitamente y no reporta una importación falsa.
- La importación se adaptó a la tabla existente `products`, cuyos campos son `Sku`, `Producto`, `Categoria`, `Subcategoria`, `descripcion`, `Image(url)` y `stock`. `Categoria` se guarda directamente como texto desde Excel, sin consultar ni exigir registros en la tabla `categories`; las vistas públicas y Admin también leen esos campos.
- Las categorías múltiples se conservan completas en `products.Categoria`. El catálogo público separa ese texto por comas al construir categorías, contar productos, mostrar subcategorías y filtrar; un producto puede aparecer en todas sus categorías sin duplicar el registro en Supabase.
- Las categorías del catálogo público ya no dependen de una lista fija: se generan desde los valores de `products.Categoria`, incluyendo categorías nuevas y categorías múltiples. Cada categoría nueva obtiene su tarjeta, entrada del menú superior, sección del catálogo, contador, subcategorías y filtro automáticamente; el panel Admin también agrega vistas para categorías detectadas.
- El panel Admin ahora requiere Supabase Auth con `app_metadata.role = 'admin'` antes de mostrar la tabla o permitir importaciones. Se agregó `supabase-admin-products.sql` con la política RLS de `products`; no se habilitó escritura anónima.
- El importador acepta archivos `.xls`, `.xlsx`, `.xlsm`, `.xlsb` y nombres con doble extensión como `.xlsb.xlsm`; SheetJS se configura para leerlos como arreglo binario y conservar macros cuando el formato las incluya.
- Las solicitudes de descripción reintentan automáticamente hasta 3 veces ante errores transitorios del Worker/Gemini (`429`, `5xx`, indisponibilidad o saturación), con espera progresiva de 3, 6 y 9 segundos.
- La importación guarda cada producto inmediatamente después de preparar su descripción mediante un `upsert` individual por `Sku`; si un producto posterior falla, los productos anteriores permanecen guardados.
- El panel Admin incluye un menú desplegable con una pestaña de Estadísticas. La importación continúa en segundo plano ante errores individuales, conserva el tiempo total, el temporizador del producto actual y una tabla con la duración y resultado de cada producto hasta iniciar una nueva importación.
